### Known hazard discovered this session

**cwd drift in Bash tool calls:** Running `cd packages/client` in one Bash call changes the working directory for ALL subsequent Bash calls in the session. This caused `npm install`, `npm audit fix`, and `rm -rf node_modules` to run inside `packages/client` instead of the monorepo root, creating a rogue standalone install and significant confusion. Recovered via `pwd && ls`.

**Rule:** After any `cd`, verify with `pwd` before running destructive or install commands. Prefer absolute paths (`/Users/mike/sites/justreadcomics`) over relative `cd` chains.
